# Student Grade Tracker

A Java console-based application for managing student grades.

## Features

- Add student details and marks
- Calculate total and percentage
- Assign grades
- Check pass or fail status
- Find and manage student records
- Calculate class average
- Identify top-performing students

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Console-based application

## Project

This project was developed as part of the CodeAlpha Java Programming Internship.
